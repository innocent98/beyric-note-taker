Stop Bot

POST/bot/{id}/stopCopy URL
https://platform.skribby.io/api/v1/bot/{id}/stop

Stop a running meeting bot. This will cause the bot to leave the meeting
and begin processing the recording.

Path Parameters

NameTypeDescription
idrequired
string<uuid>Bot ID

Responses

200Bot stopped successfullymessagestring
Example: "Meeting bot is shutting down."

401Unauthorized - Invalid API key
403Bot cannot be stopped
404Bot not found
