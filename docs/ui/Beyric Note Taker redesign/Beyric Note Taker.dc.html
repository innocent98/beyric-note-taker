How tasks are assigned

After each meeting, every action item becomes a task for the teammate named as its owner. Names are matched against each person's name and the names they appear as in meetings. Items with no match wait under Needs owner.

Roles
Owner manages billing, settings and the team.
Admin invites people and manages all tasks.
Member sees shared meetings and works on their tasks.
