## Read this first

- The design file draws **one desktop layout** (it has no `@media` rule at all: `grep -c "@media"` gives 0). It draws **no tablet or phone variants**. `docs/ui/parity-report.md` says the same ("The main-app prototype is not responsive"). The phone and tablet layouts are ours (A71).
- The file does **not** draw: "Not recorded" rows or "Send now", a notifications screen or bell, onboarding, a calendar-disconnected banner, an instant-Meet switch, a "meeting not found" page, a waiting or processing state, a Delete meeting button. (`grep` for "Not recorded", "Send now", "Notification", "Reconnect", "not found", "Processing" over all `.dc.html` files finds nothing; "instant" finds only a French sample sentence.) Where we built them they are in "lead-designed" rows.
- Some words you listed ("onboarding", "Not recorded") are therefore **not in this file**. "Set up your workspace" and "Join your team" are in `Auth.dc.html` (L146 and L182), a different file; I list them in A69 and A70 but did not audit that file otherwise.
- There is **no screen in the main app file that is plainly missing with a UI-only fix**, except the sidebar identity (A2). The real gaps are: Projects > Recurring meetings (A43, off), the sprint line on the Series page (A45), the "Connect Microsoft Outlook" button (A31), the sidebar name and email (A2), the Jira / Asana / Taiga tools (A36), and the Auth file's "Set up your workspace" (A70).
